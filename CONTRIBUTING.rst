How to Contribute
=================

Head over to: https://github.com/twisted/TxMongo and submit your bugs or feature requests.
If you wish to contribute code, just fork it, make a branch and send us a pull request.
We'll review it, and push back if necessary.

TxMongo generally follows the coding and documentation standards of the Twisted project, including the `AI Policy <https://docs.twisted.org/en/latest/development/ai-policy.html>`_. This means this project does not allow the inclusion of the outputs of generative AI tools.
